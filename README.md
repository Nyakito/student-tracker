# Student Tracker

## Project Description

The Student Tracker is a simple web-based application designed to calculate and display students' academic results based on their performance in Mathematics, English, and Science.

The project aims to simplify the process of evaluating student performance by providing the total marks, average score, grade, examination status, and personalized teacher comments in one place.

## Purpose of the Project

This project was developed as a practical exercise to apply JavaScript concepts in building an interactive web application. It demonstrates how programming can be used to solve everyday problems, reduce manual calculations, and present information in an organized and user-friendly way.

## Features

- Student name input.
- Marks entry for Mathematics, English, and Science.
- Automatic calculation of total marks and average score.
- Automatic grade assignment.
- Examination pass/fail status.
- Personalized teacher comments based on academic performance.
- Simple and user-friendly interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript
